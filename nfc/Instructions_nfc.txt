=====================================================
  SLDS FILE SIGNING SYSTEM (NFC VERSION) — HOW TO USE
=====================================================

WHAT THIS DOES:
  The Android app sends a file (e.g. a PDF) to the Windows PC
  via NFC tap only — no Wi-Fi needed. The PC digitally signs it
  and sends it back, all over NFC.

=====================================================
  PART 1 — ANDROID PHONE SETUP  (do this once)
=====================================================

STEP 1: Install the app
  - Copy "apk/app-debug.apk" to your phone and open it to install
  - If prompted about unknown sources, allow it in Settings > Security

STEP 2: Enable NFC
  - Settings > Connections > NFC — turn it on

STEP 3: Grant permissions
  - Open the app and tap Allow for every permission it requests
  - If it asks for "All files access", grant that too
  - The app should show "NFC ready" when done

=====================================================
  PART 2 — WINDOWS PC SETUP  (do this once)
=====================================================

STEP 4: Install Python
  - Download from https://www.python.org/downloads/ and install
  - During install, make sure "Add Python to PATH" is ticked

STEP 5: SCL011 Driver Installation Steps
	1.	Go to driverscape.com/download/scl011-generic-contactless-reader
	2.	Select Windows 10 64-bit and click Download
	3.	Extract the downloaded ZIP (right-click → Extract All)
	4.	Open the extracted folder
	5.	Right-click scl0102k.inf → click Install
	6.	Plug in your SCL011 reader
	7.	Check Device Manager → Smart card readers to confirm it’s detected

STEP 6: Install required Python packages
  - Open Command Prompt and run:

    pip install cryptography zeroconf

STEP 7: Plug in the USB NFC reader

=====================================================
  PART 3 — USING THE SYSTEM  (every time)
=====================================================

--- On the PC (do these first) ---

STEP 8: Start the certificate server
  - Open Command Prompt in the "ca_server" folder and run:
    python ca_server.py
  - Leave this window open

STEP 9: Start the NFC reader app
  - Start the exe.

--- On the Phone ---

STEP 10: Select the file to sign
  - Open the app, tap "Select File" and choose your PDF

STEP 11: Tap the phone to the NFC reader
  - Hold the back of the phone flat against the reader
  - Keep it still for a few seconds — the rest happens automatically
  - The file transfers, gets signed, and is sent back to the phone

STEP 12: Find your signed file
  - Phone: tap "Check Received Files" in the app
  - PC: the signed file is saved to your Desktop

=====================================================
  TROUBLESHOOTING
=====================================================

NFC not working:
  - Check NFC is enabled in phone settings
  - Make sure the phone's back is flat against the reader

"Waiting for NFC tap..." not responding:
  - Unplug and replug the NFC reader, then restart Project1.exe

"CA registration failed" on first tap:
  - Make sure ca_server.py is running (Step 8) before running Project1.exe
  - Phone and PC must be on the same Wi-Fi network for registration

App permissions issue:
  - Settings > Apps > NFC File Transfer > Permissions > enable all

"pip not found" or "python not found":
  - Reinstall Python with "Add Python to PATH" ticked
